オペアンプのフィードバック制御（とトランジスタのリニアレギュレータ）のシミュレーター

パワーエレクトロニクス 第7回 直流-直流変換（３） p26〜30 / 大阪工業大学
オペアンプの出力を、マイナスの入力 Vin− に戻します（フィードバック）。t = 0 でスイッチをオンにしてから、出力が落ち着くまでを計算します。 「回路の値」の回路のボタンで「例①：出力をそのまま戻す（p26〜27）」「例②：1 kΩ・2 kΩ で分けて戻す（p28〜29）」「トランジスタと 15 V を足したリニアレギュレータ（p30）」を選べます。 どの回路でも、出力は Vin− = Vin+ になる所で止まります（オペアンプの二つの入力は等しくなる）。 回路図の線をクリックするとその点の電位、素子をクリックすると電流（矢印の向きが正）が下のグラフに出ます。

このシミュレーターの前提
  • オペアンプ：入力には電流が流れず、出力は VS−（0 V、接地）〜 VS+ の間（p23）。出力は差 Vin+ − Vin− を積分するように動き、直流の増幅度は非常に大きい（p23 の 105〜107 程度より大きい）ので、落ち着くと Vin− = Vin+ になります。出力の変わる速さには上限（スルーレート SR）があり、差が大きい間は SR で一定の速さで変わります（式：dVout/dt = SR · tanh(2πfT(Vin+ − Vin−)/SR)、利得帯域幅 fT = 10 MHz。SR = 10 V/μs・fT = 10 MHz は LTspice の UniversalOpamp2 の既定値）。
  • スライド p27・p29 のグラフは時間の目盛りのない模式図です（直線で近づいて合流）。このシミュレーターの直線の部分が、スルーレートで変わっている所です。
  • スイッチは t = 0 でオンにして、その後はずっとオンです。例①・例② の「スイッチを入れる前の出力」（10 V か 0 V）は、p26・p28 の問いと同じく、t = 0 の値として与えます。p30 はスイッチで基準の電圧を Vin+ に入れる回路で、スイッチを入れる前はすべて 0 です。スライド p30 の 200.0 μs（スイッチオン）が、この図の t = 0 です。
  • p30 のトランジスタは 2N2222（LTspice の標準ライブラリの値。IS = 10−14 A、BF = 200、BR = 3、IKF = 0.3 A、VAF = 100 V、RB = 10 Ω、RC = 0.3 Ω、RE = 0.2 Ω）の直流の式（ガンメル・プーンの簡略形、27 °C）。リニアレギュレータのページ（第7回 p21）と同じモデルです。接合の容量は入れていません（変化はオペアンプのスルーレートで決まるため）。
  • p30 の負荷の抵抗の値はスライドに無いので、10 Ω としました（LTspice の .step の値。エミッタの電流 約 750 mA がスライドの Ie の図と合います）。p30 の Vout はオペアンプの出力（トランジスタのベースの電圧）で、負荷の電圧は vR です。
  • スライド p30 の Ie(Q1) の図は LTspice の向き（素子に流れ込む向きが正）で負に描かれています。この回路図の矢印（エミッタから出る向き）では正です。
  • 計算は 4 次のルンゲ・クッタ法（刻み 1 ns 以下）で、出力が VS+ や 0 V に届く時刻は二分法で求めています。
