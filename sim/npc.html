マルチレベルインバータ（NPC・中性点クランプ方式）のシミュレーター

パワーエレクトロニクス 第12回 直流-交流変換（２） p30〜37 / 大阪工業大学
電源を E/2 ずつ 2 つに分け、その中点（中性点 O）をダイオードでレグにつなぐと、1 つのレグで 0・E/2・E の 3 つの値を取れます（p31・34）。 それを 2 つ並べたフルブリッジ（p35）を、上と下の 2 つの搬送波と指令信号で PWM 制御すると、負荷の電圧 v は −E・−E/2・0・E/2・E の 5 つの値の階段になります（p37）。 回路図の線をクリックすると電位（電源の − の線 N を 0 V とする）、素子をクリックすると電流（矢印の向きが正）が出ます。

このシミュレーターの前提
  • スイッチとダイオードは理想。2 つの電源 E/2 は理想の直流電圧源で、中性点 O の電位は E/2 に固定です（実際の装置ではコンデンサで分けるので、中性点の電流で電位が揺れる。ここでは考えない）。
  • スイッチの組み合わせは p34 の表のとおり：S1・S2 オンで vMN = E、S2・S3 オンで E/2（電流の向きにより、上か下のクランプダイオード D5・D6 を通って中性点につながる）、S3・S4 オンで 0。S1 と S3、S2 と S4 は必ず反対です。オフの 2 つのスイッチの間は、クランプダイオードで E/2 に止まるとしました（p33：オフのスイッチには E/2 だけかかる）。
  • PWM（p35〜37。スライドは演習問題ですが、p37 に答えの波形があります）：搬送波は上（0〜1）と下（−1〜0）の 2 つの三角波で、同じ位相（周波数 mf f、t = 0 で上は 0・下は −1）。指令信号は vref = ma sin ωt。 S1：vref > 上の搬送波、S2：vref > 下の搬送波。右のレグ（S1′〜S4′）は −vref と比べます。 波形のいちばん上の帯は、塗られている間そのスイッチがオン（「S₁ オン」の帯が塗られている間は S₃ オフ、「S₂ オン」の間は S₄ オフ。右のレグも同じ）。
  • レグの電圧の平均は E/2 + (maE/2) sin ωt になるので、v（左 − 右）の基本波の振幅は maE です（ma ≤ 1、搬送波が十分に速いとき。スライドに式は無い。mf = 4 のように搬送波が遅いと数 % ずれるので、表の判定は「目安」にしています）。ma ≤ 0.5 では ±E は出ず、v は 3 つの値だけになります。
  • 計算は 4 次のルンゲ・クッタ法。指令信号と搬送波の交点（切り替えの時刻）は二分法で求めています。電流は 0 から始めて、定常状態になるまで計算します。
