このシミュレーターの前提
  • スイッチとダイオードは理想（オンで 0 Ω・オフで電流 0、電圧降下なし）。コイル・コンデンサ・抵抗も理想の素子です。
  • スライド p36 の LTspice の波形（vC ≈ 11.17 V）はダイオードのオン電圧を含んでいます。ここでは理想のダイオードなので、p35 の値では V0 / (1 − D) = 12.0 V になります。
  • オフの間にコイルの電流が 0 になると、ダイオードが止まって電流 0 のまま（電流不連続モード）になります。このときは V0 / (1 − D) より高い電圧になります。
  • vsw はスイッチの両端の電圧（スイッチ・コイル・ダイオードがつながる節点の電位）です。オンで 0 V、オフで vC（電流が止まっている間は V0）。
  • 起動の直後は vC が V0 より低いので、スイッチがオフでもコイルの電流は増えます（突入電流）。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 80〜400 分割）で、コイルの電流が 0 になる時刻は二分法で求めています。
