回路図の線（節点）をクリックすると、その点の電位（GND を 0 V とする）が下のグラフに出ます。 素子をクリックすると、その素子の電流が出ます（矢印の向きが正）。もう一度クリックすると消えます。 値を変えると、スイッチを入れた瞬間（t = 0、電流も電圧も 0）から計算し直します。

このシミュレーターの前提
  • スイッチとダイオードは理想（オンで 0 Ω・オフで電流 0、電圧降下なし）。コイル・コンデンサ・抵抗も理想の素子です。
  • スイッチは電源から右向きにしか電流を流しません。オフの間にコイルの電流が 0 になると、ダイオードも止まって電流 0 のまま（電流不連続モード）になります。
  • vsw は授業の波形と同じく、スイッチ・ダイオード・コイルがつながる節点の電位です（オンで V0、オフで 0 V）。
  • 「C をつなぐ」を外すと、第5回の p15 と同じ L–R だけの回路になります。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 80〜400 分割）で、コイルの電流が 0 になる時刻は二分法で求めています。
