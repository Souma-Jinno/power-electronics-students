三相サイリスタブリッジ（位相制御角 α による振幅制御）のシミュレーター

パワーエレクトロニクス 第13回 交流-交流変換 p19〜37 / 大阪工業大学
サイクロコンバータの部品になる、サイリスタの三相全波ブリッジです。回路図の線（節点）をクリックすると電位（電源の中性点 N を 0 V とする）、素子をクリックすると電流（矢印の向きが正）が出ます。 α を 0°→150° と動かすと、出力電圧の平均が (3/π)V0 cos α で変わる様子（p37 の図）が見られます（p37 で平均が負になっているのは、負荷に逆向きの起電力がある回生（E < 0）の例です。「回生」のボタンで試せます）。下のボタンで線間電圧 Vuv・Vvw・Vwu も重ねられます。

このシミュレーターの前提
  • 電源は三相（Y 結線、中性点 N）で、線間電圧 Vuv = V0 sin θ、Vvw = V0 sin(θ − 120°)、Vwu = V0 sin(θ + 120°)（θ = ωt）。V0 は線間電圧の振幅です（p36 と同じ）。
  • 区間 Ⅰ〜Ⅵ（60° ずつ）で流れるサイリスタの組は Ⅰ: T5・T6（w→v）、Ⅱ: T1・T6（u→v）、Ⅲ: T1・T2（u→w）、Ⅳ: T3・T2（v→w）、Ⅴ: T3・T4（v→u）、Ⅵ: T5・T4（w→u）。区間 Ⅱ の組には θ = π/3 + α でゲート信号を出します（α = 0 がダイオードのときと同じ）。
  • サイリスタは理想（順方向の電圧がかかっているときにゲート信号が来るとオン、電流が 0 でオフ）。電源のインダクタンスは 0 とし、転流は一瞬で終わるとします。電流が途切れたあとも流し始められるように、組の 2 つのサイリスタに同時にゲート信号を出します（ダブルパルス）。
  • 出力電圧の平均 (3/π)V0 cos α は「電流が途切れない」ときの式です。抵抗だけの負荷で α > 60° だと出力電圧が負になる前に電流が 0 になり（p30 の吹き出し）、平均は (3/π)V0{1 + cos(α + π/3)} になります。
  • p37 の図のように α > 90° で平均が負になるのは、電流が流れ続けるとき（負荷に逆向きの起電力 E がある回生のときなど）だけです。R と L だけの負荷では、平均電圧が負だと電流を流し続けられません（平均の電流 = 平均の電圧 / R ≥ 0）。
  • 力率は PF = P / (√3 VLL,rms Iu,rms)。電流が完全に平ら（L が大きい）なら、入力の電流は 120° 幅の矩形波で PF = (3/π) cos α、THD = 31.1 % です（第10回）。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 720 分割）で、電流が 0 になる時刻は二分法で求めています。
