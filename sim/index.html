回路のシミュレーター

パワーエレクトロニクス 第4〜7回・第9〜14回 / 大阪工業大学
授業で扱った回路（LCR回路、チョッパー、レギュレータ、整流・力率改善、インバータ、交流-交流変換、電磁ノイズ）を、ブラウザの中で動かせます。回路図の線をクリックすると電位、素子をクリックすると電流（切り替えで両端の電圧）が波形に出ます。 値を変えると、スイッチ（電源）を入れた瞬間から定常状態まで計算し直します。スマートフォンでも使えます。

第4回LCR回路の復習

コイルにスイッチング電圧
第4回 p9〜23
コイルに矩形波の電圧をかける。コイルだけでは電流が階段状に増え続け、電池 V1 = DV0 や抵抗をつなぐと定常状態に。磁気エネルギーの蓄積と放出も。
コンデンサにスイッチング電流
第4回 p24〜35
コンデンサに矩形波の電流を流す（コイルの電圧と電流を入れ替えた回路）。電圧が階段状に上がる様子と、電流源・抵抗をつないだときの定常状態、電気エネルギー。
RLC直列回路（共振）
第4回 p36〜41
単一の周波数の交流で、インピーダンス特性と共振を見る。共振では vL と vC が打ち消し合い、L と C の間でエネルギーをやり取りする。

第5回直流-直流変換（１）チョッパー

降圧チョッパー
第5回 p5〜25
電圧を下げる回路。スイッチのオン・オフで、出力が DV0 になる様子を、起動から定常状態まで見る。C を外した L–R だけの回路も。
昇圧チョッパー
第5回 p26〜36
電圧を上げる回路。オンでコイルにためて、オフで電源と足して出す。vC = V0/(1 − D)、電流不連続モードも。
昇降圧チョッパー
第5回 p37〜47
上げも下げもできる回路。出力の向きが反転する（vC = −D/(1 − D)·V0）。スライドの降圧・昇圧の例つき。

第6回直流-直流変換（２）絶縁形

変圧器の励磁電流
第6回 p14〜30
±パルスや、直流をスイッチで切ったときの励磁電流 Im。負荷をつなぐと I1 = Im + (n2/n1)I2。スイッチを切ると Im が 2次側に移り、τ = L2/R で減る。
フォワードコンバータ
第6回 p31〜34
変圧器で絶縁した降圧チョッパー。励磁電流と、リセット巻線で磁束を元に戻す動きを見る。vR = D(n2/n1)V0。
フライバックコンバータ
第6回 p35〜40
変圧器で絶縁した昇降圧チョッパー。オンで鉄心にためて、オフで 2次側に出す。出力は入力と同じ向き（D/(1 − D)·(n2/n1)V0）。

第7回直流-直流変換（３）

リニアレギュレータ
第7回 p9〜22
基準電圧源（またはツェナーダイオード）とトランジスタで降圧する。Vout = Vref − VBE、残りの電圧は熱に。負荷を変えたときの変動や、入力のリプルも。
オペアンプのフィードバック制御
第7回 p26〜30
出力をマイナスの入力に戻すと Vin− = Vin+ になる。スルーレートで出力が近づく様子と、トランジスタを足したリニアレギュレータ（負荷によらず 7.5 V）。

第9回交流-直流変換（１）整流回路

単相半波整流（ダイオード 1 つ）
第9回 p6〜11・14〜21
R・C・L・C∥R・L＋R の負荷を切り替え。逐次近似で描いた波形の答え合わせ。リプル電圧 ΔV と時定数（p19）。
単相全波整流（ダイオードブリッジ）
第9回 p22〜35
期間 I・II の電流の経路。キャパシタインプット形のリプル電圧 ΔV、チョークインプット形のリプル電流 ΔI と力率。

第10回交流-直流変換（２）力率改善

交流回路の電力と力率（R・L・C と整流回路）
第10回 p9〜42
瞬時電力とその平均（有効電力）、皮相・無効電力、力率 cos φ。整流回路の歪んだ電流の高調波・THD・力率も。
昇圧形（ブースト形）PFC
第10回 p43〜46
ブリッジ＋昇圧チョッパーで、電源の電流を電圧と同じ形に。平均電流制御（CCM）・臨界モード（TM）・ヒステリシス・制御なしで力率と THD を比べる。
トーテムポール・ブリッジレス PFC
第10回 p47〜48
高速の脚 Q₁・Q₂ と低速の脚 Q₃・Q₄ で、ブリッジなしに力率改善。期間 I・II で動く素子が入れ替わり、電流が通る半導体は 2 個（昇圧形は 3 個）。

第11回直流-交流変換（１）インバータ

ハーフブリッジインバータ
第11回 p6〜8
電源 2 つとスイッチ 2 つで ±E の方形波を作る。R・L・L＋R 負荷、デッドタイムと還流ダイオードの有無も。
フルブリッジインバータ
第11回 p8〜30
S1・S4 と S2・S3 を交互にオン。三角波の iL、スイッチの電流、還流電流の4区間、デッドタイム（ダイオードなしで大電圧）を見る。

第12回直流-交流変換（２）振幅制御

フルブリッジの位相シフト制御
第12回 p16〜20
右のレグを Δt だけ早めて 0 の区間を作る。基本波の振幅 (4E/π)cos(πΔt/T) が小さくなる様子。
正弦波 PWM（バイポーラ・ユニポーラ）
第12回 p21〜29
指令信号と搬送波でフルブリッジを切り替える。R-L 負荷の電流のリプルと、電圧・電流の高調波のスペクトル。
NPC 3レベルインバータ
第12回 p30〜37
電源を E/2 ずつに分け、中性点をダイオードでつなぐ。上下 2 つの搬送波の PWM で、負荷の電圧が 5 つの値の階段に。

第13回交流-交流変換

交流位相調整回路（サイリスタ・トライアック）
第13回 p7・13〜16
位相制御角 α でサイリスタをオンさせ、負荷電圧の実効値を調整する。抵抗だけと R-L 負荷、α < φ のときの落とし穴、力率と THD も。
三相サイリスタブリッジ（振幅制御）
第13回 p19〜37
α を 0°→150° と変えると、出力電圧の平均が (3/π)V0 cos α で変わる（p37）。電流が途切れるとき・回生のときも。
サイクロコンバータ
第13回 p38〜39
正群・負群の 2 つのブリッジで、α を時間とともに変えて低い周波数の交流を作る。休止期間と、入力の約 1/3 以下という制限。
マトリクスコンバータ
第13回 p40〜44
9 個の双方向スイッチを PWM でつなぎかえ、入力の波形の切れ端から好きな周波数の正弦波を作る。入力より高い周波数も。
間接式の周波数変換（AC→DC→AC）
第13回 p4・5・18
ダイオード整流 → DC リンクコンデンサ → インバータ。直接式との比較用。コンデンサの大きさと入力の力率。

第14回電力変換で生じる電磁ノイズ

スイッチング波形（台形波）の高調波
第14回 p14〜16
台形波のフーリエ級数のスペクトル。1/(πτ) から −20 dB/decade、1/(πτr) から −40 dB/decade。周期 T や立ち上がり時間 τr を短くすると高い周波数の成分が増える。
寄生成分によるリンギング（RLC 直列）
第14回 p48〜53
配線の L・R とダイオードの C が作る共振 f0 = 1/(2π√(LC))。速い切り替えで vC が約 2 倍に跳ね、立ち上がり時間 tr を遅くすると小さくなる。
