変圧器の励磁電流のシミュレーター

パワーエレクトロニクス 第6回 直流-直流変換（２）p14〜30 / 大阪工業大学
変圧器の1次側に電圧 v1 をかけたときの、励磁電流 Im・1次側の電流 I1・2次側の電流 I2 を見ます。 「回路の値」の電源で「±パルス（p19〜25）」と「直流＋スイッチ（p29〜30）」、負荷で「なし」と「抵抗 R」を選べます。 回路図の線をクリックするとその点の電位、素子をクリックすると電流（矢印の向きが正）、鉄心（真ん中の2本線）をクリックすると励磁電流 Im が下のグラフに出ます。

このシミュレーターの前提
  • 変圧器は結合係数 1 の結合コイルです（巻線の抵抗・鉄心の損失や飽和なし）。1次の自己インダクタンスを L とすると、2次は L2 = (n2/n1)2L。巻線の電圧は巻数に比例し（v2 = (n2/n1)v1、○ の側が＋）、電流は I1 = Im + (n2/n1)I2（p18 の I1 = Im + Iℓ、n1Iℓ = n2I2）、励磁電流は v1 = L dIm/dt で決まります。
  • ±パルス：v1 は 0 ≤ t < ton で +V、T/2 ≤ t < T/2 + ton で −V、ほかは 0 を周期 T でくり返します（ton は T/2 まで）。0 V の間は v1 = 0 なので Im は一定のままです。t = 0 で Im = 0。Im は負荷によらず、v1 だけで決まります。
  • 直流＋スイッチ：オンの間は ±パルスの +V と同じです。オフにすると I1 = 0 なので、Im は全部 2次側に移って I2 = −(n1/n2)Im（矢印と逆向き）になります。2次側は L2 と R の回路なので、τ = L2/R で減っていきます。このとき v2 = RI2 = −(n1/n2)RIm、v1 = (n1/n2)v2 = −(n1/n2)2RIm、スイッチの両端には V − v1 = V + (n1/n2)2RIm がかかります。
  • 直流＋スイッチで負荷がないと、オフで Im の行き場がなくなり、電圧が限りなく大きくなります（実際はスイッチが壊れるか、火花が飛ぶ）。なので、この組み合わせは選べないようにしています。
  • スイッチは 0 ≤ t < ton でオン（ton は 0.9T まで）。オフの間（T − ton）に Im が 0 まで戻りきらないと少しずつ残るので、何周期か回して定常状態にしています。スライド p30 の値では、残りは e−9/2 ≈ 1 % です。
  • 電源・スイッチ・抵抗は理想の素子です。計算は区間ごとの式（傾きが一定の直線と、指数関数）で求めています。
