パワーエレクトロニクス 第10回 交流-直流変換（２） p9〜42 / 大阪工業大学
交流の電源 vS = v0 sin ωt に負荷をつなぎ、瞬時電力 pS = vS iS（グラフのいちばん上の段。橙は電源 → 負荷、紫は負荷 → 電源に戻る電力）と、その平均（有効電力）・力率を見ます。 「負荷」を切り替えると、抵抗・コンデンサ・コイルのほか、前回の 2 つの整流回路（電流が歪む）も選べます。 回路図の線（節点）をクリックすると電位、素子をクリックするとその電流（矢印の向きが正）がグラフに出ます。値を変えると計算し直します。

このシミュレーターの前提
  • 電源は理想の交流電源 vS = v0 sin ωt（ω = 2πf）。iS は電源の上の端子から右へ出る向きが正、瞬時電力 pS = vS iS は電源が負荷へ送る向きが正です（p9）。素子はすべて理想です。
  • 有効電力 P = pS の 1 周期の平均、皮相電力 = Vrms Irms、力率 PF = P / (Vrms Irms)（p24〜25）。表の「シミュレーション」は、最後の 1 周期の波形を数値積分した値です。無効電力は、正弦波のときの VrmsIrms sin φ と比べるため、√((VrmsIrms)² − P²) に電流の基本波の位相 φ の符号をつけて出しています。
  • φ は電流の位相（iS = i0 sin(ωt + φ)、p9）。電流が進む（コンデンサ）と φ > 0、遅れる（コイル）と φ < 0 です。スライド p28 のコイルの図は「φ = π/2」と書いて矢印で遅れを表していますが、この式の書き方では φ = −π/2 です（cos φ = 0 は同じ）。
  • R・C・R ∥ C は電源に直接つながるので、電流はすぐに定常状態です。コイルだけの負荷は、0 から始めると電流の直流分がいつまでも消えない（抵抗がないので減衰しない）ため、定常状態の電流から始めています。R + L は電流 0 から始めます（直流分が時定数 L/R で消える）。
  • チョークインプット形：ブリッジの出力の電圧は |vS|、コイルの電流 iL は 0 にならず、電源の電流は iS = sign(vS) iL です。L/R が周期よりずっと長いと iL がほぼ一定になり、電源の電流は方形波に近づきます（p38）。そのときだけ、方形波の式（i2n+1 = 4i0/(π(2n+1))、THD = √(π²/8 − 1)、PF = 0.900、p38・p41）と合います。
  • キャパシタインプット形：電源の配線などの抵抗 Rs を入れています（これがないと、コンデンサに流れ込む電流が無限大になる）。ダイオードは |vS| > vC の間だけ流れ、電流は (|vS| − vC)/Rs です。t = 0 で vC = 0 から始めるので、起動直後には大きな突入電流が流れます。
  • 整流回路の節点の電位は、直流側の − の線（GND）を 0 V としています。ダイオードがすべて止まっているときの電源側の 2 つの節点は電位が決まらないので、vC/2 を中心に ±vS/2 と表示しています。
  • THD は電流の 2〜99 次の高調波（フーリエ係数を数値積分）の実効値と基本波の実効値の比（p35）です。I1 は基本波の実効値（= 振幅 i1 / √2）。電圧が正弦波なので、平均電力は基本波の電流だけが運びます（直交性、p32・p39）。キャパシタインプット形で電流のパルスが極端に細いときは、100 次以上の高調波が残るので、THD がわずかに小さく出て、「I1√(1 + THD²)」「力率の式」の行が 1〜2 % ずれることがあります。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 1000 分割。時定数 L/R・RsC が短いときはその 1/3）で、ダイオードがオン・オフする時刻は二分法で求めています。時定数が極端に短い組み合わせ（周期の数万分の 1 以下）では、ブラウザが固まらないように、計算の中だけ L または Rs を大きくして時定数を刻みの 3 倍にしています（表の上に表示。周期に比べてずっと短いので、波形と力率はほとんど変わりません）。
