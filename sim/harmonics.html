スイッチング波形（台形波）の高調波のシミュレーター

パワーエレクトロニクス 第14回 電力変換で生じる電磁ノイズ p14〜16 / 大阪工業大学
スイッチ S1・S2 を切り替えて作る電圧 vsw は、立ち上がり時間 τr のある台形波です（p14）。 これをフーリエ級数に分けると、基本周波数 1/T の整数倍の高調波（ノイズの原因）が並びます。下のスペクトル（振幅を dB で、周波数を対数で）では、 振幅は 1/(πτ) を過ぎると −20 dB/decade、1/(πτr) を過ぎると −40 dB/decade で小さくなります。 周期 T を短くすると（p15）、立ち上がり時間 τr を短くすると（p16）、高い周波数の成分が大きくなります。例のボタンを続けて押すと、前の結果が重なって比べられます。 波形の「第 N 次までの和」で、高調波を足していくと台形波に近づく様子も見られます。

このシミュレーターの前提
  • vsw は p14 の台形波です：周期 T、高さ A、立ち上がり時間 τr と立ち下がり時間 τf は同じ（τr = τf）で直線。パルス幅 τ = DT は、立ち上がりの中点から立ち下がりの中点までの時間です（p14 の図の点線の高さ）。t = 0 が立ち上がりの始まりです。
  • スイッチ S1・S2 は、切り替えに τr かかり、その間 vsw が直線で変わるものとしています（実際のスイッチの切り替えの形は直線ではありません）。負荷はつないでいません。
  • スペクトルの点（シミュレーション）は、波形の 1 周期を数値で積分したフーリエ係数 cn = (1/T)∫vsw(t) e−jnω0t dt の大きさ |cn| です（波形の折れ点の間は直線なので、区間ごとに厳密に積分しています）。太い線は p14 の式の上側の包絡線（sin を 1 とした直線）で、1/(πτ) と 1/(πτr) で折れます。
  • dB は 20 log10(|cn| / 1 V)（p17〜19：電圧なので 20 倍、基準は 1 V）。|cn| は複素フーリエ係数の大きさで、その周波数の正弦波の振幅は 2|cn| です（スライドの図と同じく |cn| を描いています。A = 1 V、D = 0.5 で基本波が約 −10 dB）。
  • D = 0.5 では偶数次の高調波は 0 になる（点が出ない）ので、点は奇数次だけです。sin が 0 になる周波数では点が下に落ちます（p15・16 の図の谷）。
  • p16 の図の縦の破線は、1/(πτr)（3.2 kHz・31.8 kHz・318 kHz）より少し右に描かれています。このページでは式どおりの位置に描いています。
  • 点が多すぎないように、スペクトルは 2 万次まで（または 1/(πτr) の 30 倍の周波数まで）計算しています。τr は DT と (1 − D)T より長くできないので、長すぎるときは短くしています。
