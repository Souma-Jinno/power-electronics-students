ダイオードブリッジのあとに昇圧チョッパー（第6回）をつなぎ、スイッチ Q のオン・オフでコイルの電流 iL を、電源の電圧と同じ形（目標 iref ∝ |vS|）に制御します（p43〜44）。 「制御」を切り替えると、平均電流制御（p44 の CCM）・臨界モード（p44 の TM）・ヒステリシス制御・制御なし（Q オフのまま＝キャパシタインプット形と同じ）で、電源の電流の形と力率・THD を比べられます（下の表）。 回路図の線をクリックすると電位（直流側の − の線が 0 V）、素子をクリックすると電流が出ます。スイッチングを見るには「定常状態」で「交流の周期の数」を 1/50 などにして拡大してください。

このシミュレーターの前提
  • 電源は vS = V0 sin ωt。ダイオード・スイッチ Q・コイル・コンデンサ・抵抗はすべて理想です（電圧降下・損失なし）。電源の電流は、ブリッジを通るので iS = sign(vS) iL。期間 I（vS > 0）は D1・D4、期間 II は D2・D3 が流れます（p46）。
  • Q オン：L diL/dt = |vS|（電流が増える）。Q オフ：電流は Db を通って C・R へ、L diL/dt = |vS| − vC（減る）。電流が 0 になると、ブリッジも Db も止まります（電流不連続）。
  • 目標の電流 iref = Ipk|sin ωt|。実際の PFC は出力の電圧をゆっくりフィードバックして Ipk を決めますが、ここでは入力と出力の電力のつり合い V0Ipk/2 = Vo*²/R から決めた値に固定しています。そのため、出力の電圧の平均は目標 Vo* に落ち着きます（時定数は約 RC/2）。
  • 平均電流制御（模式）：周波数 fsw 一定。各周期の始めに、その周期の終わりの電流が「目標 − リプルの半分」になるオン時間を計算して決めます（リプルの中心＝周期の平均が目標になる）。電流が 0 から始まる周期（ゼロクロスの近く）は、三角の面積で平均が目標になるオン時間にしています。臨界モード（TM）：オン時間 ton = 2IpkL/V0 一定。オフの間に電流が 0 まで下がったら、すぐ次のオン。各周期の電流は 0 から 2iref までの三角になり、その平均が iref です（p44 の右）。入力フィルタがないので、電源の電流そのものは三角の列で、実効値は √(4/3) 倍、力率は √3/2 ≈ 0.866 になります（THD（2〜40 次）はほぼ 0。実際は EMI フィルタで平均の電流 ≈ 正弦波になり、力率はほぼ 1）。ton が 1/1500 周期より短くなる値では 1/1500 周期に固定しています（そのときは出力の電圧が目標からずれる）。ヒステリシス制御：iL が iref + 幅/2 を超えたらオフ、iref − 幅/2 を下回ったらオン（周波数は一定でない）。iref < 幅/2 のゼロクロス付近では電流が 0 のままになります。
  • 入力フィルタ（EMI フィルタ）は入れていません。電源の電流にはスイッチングのリプルがそのまま含まれるので、「THD（全体）」はリプルも含めた値、「THD（2〜40 次）」は電源の周波数の 40 倍までの高調波だけの値です。
  • t = 0 で、コンデンサは電源の山 V0 まで充電されている（起動の突入電流は考えない）とし、平均電流制御では vS の山の 1 スイッチング周期あとで終わります（「定常状態」を拡大すると、リプルがいちばん大きい山のスイッチングが見える）。オンの割合 D と振れ幅 ΔIL は、山をはさむ 2 スイッチング周期で測り、昇圧チョッパーの式（fsw が電源の周波数よりずっと高く、1 周期の間 |vS| がほぼ一定とみなせるときの式）と比べています。
  • ダイオードの損失の見積もり（p45）：1 個あたり VF = 1 V として、理想素子で計算した電流から 2VF × (|iS| の平均) をブリッジの損失としました。正弦波の電流なら、入力の電力との比は 2VF(2Ipk/π) / (V0Ipk/2) = 8VF/(πV0)（AC100 V で約 1.8 %）。電流は、ブリッジの 2 個のほかに Q か Db の 1 個、合わせて常に 3 個の半導体を通るので、表にはその 3 個分 12VF/(πV0)（AC100 V で約 2.7 %。p45 の「約 2 %」は同じ考え方のおおまかな値で、VF の置き方で変わります）も並べました。
