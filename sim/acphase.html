交流位相調整回路（サイリスタ・トライアック）のシミュレーター

パワーエレクトロニクス 第13回 交流-交流変換 p7・p13〜16 / 大阪工業大学
回路図の線（節点）をクリックすると、その点の電位（電源の下の線を 0 V とする）が下のグラフに出ます。 素子をクリックすると、その素子の電流が出ます（矢印の向きが正）。位相制御角 α を動かすと、サイリスタがオンする時刻が変わり、負荷電圧の実効値が変わります。 値を変えると、電源を入れた瞬間（t = 0、電流 0）から計算し直します。 最初はスライド p15〜16 の例（トライアック、抵抗だけ、α = 60°）です。「負荷」を「R + L」にするとコイルの影響が見られます。

このシミュレーターの前提
  • 電源は vS = V0 sin ωt（θ = ωt）。サイリスタは理想で、「順方向の電圧がかかっているときにゲート信号が来るとオンし、電流が 0 になるとオフする」とします（オンの間の電圧降下は 0）。
  • T1 のゲート信号は θ = α（+ 2π の倍数）、T2 は θ = π + α。T1 と T2 の逆並列（p14〜15）は、1 つの素子にまとめたトライアックと同じ動きです。
  • 抵抗だけの負荷では、電流は電圧と同時に 0 になるので、サイリスタは θ = π（T2 は 2π）でオフします。p16 の負荷電圧の実効値は VR,rms = V0√{(π − α + ½ sin 2α) / (2π)}（サイリスタ 1 個の p13 は 2π が 4π）。
  • コイルを入れると、電流は電圧より遅れて、θ = π を過ぎても流れ続けます（オフする角度 β は sin(β − φ) = sin(α − φ) e−(β−α)/tan φ、φ = tan−1(ωL/R)）。その間、負荷には負の電圧がかかります。
  • α < φ のとき：短いゲートパルスだと、T2 のパルスが来た時刻にまだ T1 が流れていて、T2 はオンできません（パルスが無駄になる）。T1 だけが動いて、負荷に直流が流れます。「半周期の終わりまでゲート信号を続ける」にすると、T1 の電流が 0 になった瞬間に T2 がオンして、ふつうの正弦波（α によらない）になります。
  • 力率は PF = P / (VS,rms Irms)。電源は正弦波なので PF = (I1/Irms) cos φ1（第10回の「ひずみ率 × 変位率」）。THD は電流の基本波 I1 に対する、それ以外（直流も含む）の実効値の比です。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 720 分割）で、電流が 0 になる時刻は二分法で求めています。
