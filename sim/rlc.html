RLC直列回路（共振）のシミュレーター

パワーエレクトロニクス 第4回 LCR回路の復習 p36〜41 / 大阪工業大学
スイッチングではなく、単一の周波数の交流 vS = Vm sin ωt（ω = 2πf）を L・C・R の直列回路にかけます（p36）。 周波数 f を動かすか、下のインピーダンス特性のグラフをクリックすると、その周波数で計算し直します。ωL = 1/(ωC) の共振のとき、vL と vC が打ち消し合い、電流がいちばん大きくなります。 回路図の線をクリックするとその点の電位、素子をクリックすると電流（矢印の向きが正）が波形に出ます。電源は t = 0（電流 0、vC = 0）でつなぎます。

このシミュレーターの前提
  • 電源は理想の交流電圧源 vS = Vm sin ωt。L・C・R は理想の素子です。式は L di/dt = vS − Ri − vC、C dvC/dt = i。
  • 授業の式（p37）：Z = jωL + 1/(jωC) + R = j(ωL − 1/(ωC)) + R。定常状態の電流の振幅は Im = Vm/|Z|、位相の遅れは φ = tan−1{(ωL − 1/(ωC))/R}（負なら進み）。
  • 共振：ωL = 1/(ωC)、つまり f0 = 1/(2π√(LC))。p38 の値（L = 1 mH、C = 10 μF、R = 1 Ω）では f0 ≈ 1.59 kHz で、|Z| = R = 1 Ω まで下がります。
  • 同じ電流が流れる直列回路なので、vC と vL の振幅の比は (1/(ωC))/(ωL) = (f0/f)2。L と C のエネルギーの最大値の比も同じです（p40・p41）。
  • エネルギーの和 ½Li2 + ½CvC2 は、定常状態で ½Im2(L sin2 + cos2/(ω2C)) の形になり、その変動（最大 − 最小）は ½Im2|L − 1/(ω2C)|。共振のときだけ 0（いつも一定、p39）です。
  • 電源をつないだ直後は、固有の振動（e−Rt/(2L) で減る）が重なります。「起動から最後まで」で見られます。表は最後の 1 周期の値です（振幅は基本波の成分）。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 400 分割以上。固有の振動が速いときはもっと細かく）。
