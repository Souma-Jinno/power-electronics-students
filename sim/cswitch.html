スイッチング電流 iin(t)（0 ≤ t < DT で I0、残りは 0 を周期 T でくり返す）をコンデンサ C に流します。コイルのページ（p9〜23）の電圧と電流を入れ替えた回路です（p26）。 「回路の値」の負荷のボタンで「なし（p24〜28）」「電流源 I1（p29〜31）」「抵抗 R（p32〜35）」から選べます。 回路図の線をクリックするとその点の電位、素子をクリックすると電流（矢印の向きが正）が下のグラフに出ます。値を変えると、t = 0（vC(0) = 0）から計算し直します。

このシミュレーターの前提
  • iin(t) は理想の電流源（両端がどんな電圧になっても決まった電流を流す）。コンデンサ・抵抗・負荷の電流源 I1 も理想の素子です。t = 0 で vC = 0。
  • KCL（p29）：−iin + iC + iout = 0、枝構成式：iC = C dvC/dt。負荷なしは iout = 0、電流源は iout = I1（下向き）、抵抗は iout = vC/R。
  • p29〜33 の図では負荷の電流源の丸の中の矢印が上向きですが、横の I1 の矢印と KCL の式に合わせて、ここでは下向き（上の線から電流を引き抜く向き）に描いています。
  • 負荷なしでは、オフの間 iC = 0 なので電圧は一定のまま、オンのたびに I0DT/C ずつ上がります（p25・p27、定常状態にならない）。電流源では、I1 = DI0 のときだけ定常状態になります（p30）。I1 ≠ DI0 だと、1 周期ごとに T(DI0 − I1)/C ずつ上がり（下がり）続けます（負の電圧にもなる）。
  • 抵抗のときの Δv = DT(1 − D)I0/C（p31）は、抵抗の電流を一定 DI0 とみなした 1 回目の近似（p32）の式です。厳密な振れ幅は RI0(1 − a)(1 − b)/(1 − ab)（a = e−DT/τ、b = e−(1−D)T/τ、τ = RC）で、τ が T の数倍以上あれば差は 0.1 % 以下です。抵抗の電流の平均 DI0 は厳密です（1 周期で iC の平均が 0 になるため）。
  • 起動の時定数：抵抗のとき、電圧の 1 周期ごとの平均は DI0R に e−t/τ（τ = RC）で近づきます。表の値は、最初の 2 周期の平均の差の比から求めています。
  • p35 の iin(t) のグラフの「V0」は I0、p25 の「vC = 0.0 [A]」は [V] のことです。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 40〜400 分割、τ が短いときはもっと細かく）で、iin の切り替わりの時刻はちょうど刻みの境目に置いています。
