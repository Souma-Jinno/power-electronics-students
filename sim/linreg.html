パワーエレクトロニクス 第7回 直流-直流変換（３） p9〜10・p16〜18・p21〜22 / 大阪工業大学
回路図の線（節点）をクリックすると、その点の電位（GND を 0 V とする）が下のグラフに出ます。 素子をクリックすると、その素子の電流が出ます（矢印の向きが正）。トランジスタは、本体がコレクタ電流 Ic（両端の電圧は VCE）、ベースの足がベース電流 Ib（両端の電圧は VBE）、エミッタの足が出力の電流 Iout です。 入力の電圧 V0 にリプル（整流した後の脈動を想定した 120 Hz の正弦波）をのせると、出力がほとんど揺れないこと（p4「ノイズが小さい」）と、入力が下がりすぎるとトランジスタが飽和して出力が崩れることが見られます。

このシミュレーターの前提
  • コイルもコンデンサも無いので、各時刻の値はその時刻の入力の電圧 V0(t) = V0 + ΔV0 sin(2π·120 t) だけで決まります（起動の過渡はありません）。ΔV0 = 0 なら、どの時刻も同じ値です。表は最後の 1 周期（1/120 s）の平均です。
  • 授業の計算（VBE・h 一定）：p16〜18 と同じく VBE を一定、h = Ic / Ib を一定とします（Iout = Ic + Ib）。VCE が 0.2 V より小さくなる所は飽和（p13）として、Vout = V0 − 0.2 V で止めます（このモデルでは飽和したときのベース電流は正しくありません）。ツェナーは VZ = 4.7 V（1N750 の公称値）で一定、逆向きには電流を流さない、とします。
  • 2N2222・1N750 のモデル：p21〜22 の LTspice と同じ素子の値（LTspice の標準ライブラリ。2N2222：IS = 10−14 A、BF = 200、BR = 3、IKF = 0.3 A、VAF = 100 V、RB = 10 Ω、RC = 0.3 Ω、RE = 0.2 Ω。1N750：BV = 4.7 V、IBV = 20.245 mA、NBV = 1.7、RS = 0.25 Ω）で、直流の式（ガンメル・プーンのモデルの簡略形、27 °C）を解いています。電流が大きいほど VBE が大きくなり、h は小さくなります（BF = 200 でも、0.37 A では約 97）。
  • p21 の LTspice の値（VZ = 4.6604 V）と、このモデルの値（4.669 V）は約 9 mV 違います。ツェナーのモデルの細部（LTspice が降伏の式に使う補正）の違いで、Vout では 0.2 % の差です。負荷を変えたときの変化の幅（p22：Vout 約 0.2 V、VZ 約 0.02 V、VBE 約 0.18 V）は一致します。
  • 基準電圧源は理想の電池です。p9 の「電流は供給できない」は「負荷の電流を流す役ではない」という意味で、このシミュレーターではベース電流 Ib だけが基準電圧源を流れます。効率の式（p18）は η = VoutIout / (V0 × 入力の電流) で、シミュレーションの η は（出力の電力）／（電源 V0 と基準電圧源が出す電力の和）です。
  • スライド p9・p10 の VCE の矢印は矢じりがエミッタ側ですが、高電位はコレクタ側なので、この図では p16 と同じくコレクタ側に矢じりを描いています。
