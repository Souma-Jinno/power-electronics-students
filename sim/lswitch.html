スイッチング電圧 vin(t)（0 ≤ t < DT で V0、残りは 0 を周期 T でくり返す）をコイル L にかけます。 「回路の値」の負荷のボタンで「なし（p9〜12）」「電池 V1（p13〜18）」「抵抗 R（p19〜23）」から選べます。 回路図の線をクリックするとその点の電位、素子をクリックすると電流（矢印の向きが正）が下のグラフに出ます。値を変えると、t = 0（iL(0) = 0）から計算し直します。

このシミュレーターの前提
  • vin(t) は理想の電圧源（どちら向きの電流も流せる）。コイル・抵抗・電池も理想の素子です（コイルの巻線抵抗は 0）。t = 0 で iL = 0。
  • KVL（p15）：vin − vL − vout = 0、枝構成式：vL = L diL/dt。負荷なしは vout = 0（p9 と同じく、コイルが電源に直接つながる）、電池は vout = V1、抵抗は vout = R iL。
  • 負荷なしでは、オフの間 vL = 0 なので電流は一定のまま、オンのたびに V0DT/L ずつ増えます（p11〜12、定常状態にならない）。電池では、V1 = DV0 のときだけ I と II の面積が等しくなり、定常状態になります（p16）。V1 ≠ DV0 だと、1 周期ごとに T(DV0 − V1)/L ずつ増え（減り）続けます（負の電流にもなる）。
  • 抵抗のときの ΔI = DT(1 − D)V0/L（p18）は、抵抗の電圧を一定 DV0 とみなした 1 回目の近似（p19）の式です。厳密な振れ幅は (V0/R)(1 − a)(1 − b)/(1 − ab)（a = e−DT/τ、b = e−(1−D)T/τ、τ = L/R）で、τ が T の数倍以上あれば差は 0.1 % 以下です。τ が T と同じくらいまで小さくなると、近似の式は大きめに出ます（表に厳密な値も出します）。抵抗の電圧の平均 DV0 は近似ではなく厳密です（1 周期で vL の平均が 0 になるため）。
  • 起動の時定数：抵抗のとき、電流の 1 周期ごとの平均は DV0/R に e−t/τ（τ = L/R）で近づきます。表の値は、最初の 2 周期の平均の差の比から求めています。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 40〜400 分割、τ が短いときはもっと細かく）で、vin の切り替わりの時刻はちょうど刻みの境目に置いています。
