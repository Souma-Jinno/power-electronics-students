ハーフブリッジインバータ（方形波）のシミュレーター

パワーエレクトロニクス 第11回 直流-交流変換（１） p6〜8 / 大阪工業大学
電源を 2 つ（それぞれ E）直列にして、その間の点 O と、上下 2 つのスイッチ（1 本のレグ）の中点 a の間に負荷をつなぎます（p8 の左の回路）。 S1 と S2 を半周期ずつオンにすると、負荷の電圧は +E と −E を行き来する方形波になります（p6〜7 の「回路を切り替える」をスイッチ 2 つでやる）。 フルブリッジと比べてスイッチは 2 つで済むが、電源が 2 つ必要です。 回路図の線をクリックすると電位（2 つの電源の間 O を 0 V とする）、素子をクリックすると電流（矢印の向きが正）が下のグラフに出ます。

このシミュレーターの前提
  • 電源は 2 つとも E（p7 の 2 つの電源と同じ。合わせて 2E）。負荷の電圧・電流は、a から O に向かう向き（回路図の左向き）を正とします。こうすると S1 オンで +E、S2 オンで −E になり、フルブリッジ（p10〜16）と同じ式が使えます。
  • スイッチは理想（オンで 0 Ω、どちら向きにも流せる）。オンのスイッチは負荷の電流が逆向きのときもそのスイッチ自身が流し、還流ダイオードはデッドタイムの間だけ流れます（フルブリッジの p20・p26〜30 と同じ考え方）。ダイオードも理想（電圧降下 0）です。
  • ゲート信号：S1 は 0〜T/2、S2 は T/2 + td 〜 T、T の後にも td のデッドタイム（最初の周期だけは t = 0 から S1 がオン）。td は周期の 20 % までにしています。
  • デッドタイムの間：還流ダイオードがあると、i > 0 なら D2（負荷に −E）、i < 0 なら D1（負荷に +E）が流れます。ダイオードがないと、オフのスイッチ（10 kΩ とした）に電流が流れ込んで大電圧がかかります（第11回 p22・p24）。
  • オフのスイッチには、2 つの電源を合わせた 2E がかかります（フルブリッジは E）。
  • 負荷が L だけのときは抵抗がないので、電流の平均は最初の値のまま変わりません。「i(0) = −TE/(4L)」を選ぶと p12 と同じ ±TE/(4L) の三角波になります。L＋R の定常状態の山は (E/R) tanh(T/(4τ))、τ = L/R です。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 400 分割）。ゲートの切り替わりは区間の境目に置き、ダイオードの電流が 0 になる時刻は二分法で求めています。
