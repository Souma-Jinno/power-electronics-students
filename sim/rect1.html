単相半波整流回路（ダイオード 1 つ）のシミュレーター

パワーエレクトロニクス 第9回 交流-直流変換（１） p6〜11・14〜21 / 大阪工業大学
交流電源 vS にダイオード 1 つと負荷をつないだ半波整流回路です。負荷を「R だけ（p6〜7）」「C だけ・L だけ（p10〜11）」「C と R の並列（p14〜19）」「L と R の直列（p20〜21）」から選べます。 回路図の線をクリックすると電位（電源の下の線を 0 V とする）、素子をクリックすると電流（矢印の向きが正）が下のグラフに出ます。 値を変えると、電源を入れた瞬間（t = 0、コンデンサの電圧 0・コイルの電流 0）から計算し直します。

このシミュレーターの前提
  • 電源は vS = V0 sin ωt（ω = 2πf、T = 1/f）。V0 は振幅（ピーク）です。家庭用のコンセントの 100 V は実効値なので、振幅は 100√2 ≈ 141 V です（p5 の図は山が 100 V になっていますが、p19 の計算は振幅 100 V）。
  • ダイオードは理想（p6：pn 接合のオン電圧は無視）で、順方向の電流が流れる間は電圧 0、電流が 0 になると止まり、逆向きには流しません。電源の内部抵抗や配線の抵抗も 0 とします。
  • C をつないだとき、ダイオードが流れている間は vC = vS で、コンデンサの電流は iC = C dvS/dt。ダイオードの電流 C dvS/dt + vS/R が 0 になる角度 θoff = π − tan−1(ωCR)（山の少し後）で止まり、その後は vC が時定数 τ = CR で下がります。vS が vC に追いつくと、また流れ始めます。
  • p18 のリプル電圧の式 ΔV = (T/CR) Vout は「周期 T の間ずっと、一定の電流 Vout/R で放電する」と考えたワーストケース（大きめ）の見積もりです。実際に放電する時間は T より短く、電圧が下がると放電の電流も減るので、T/τ が小さい（τ が周期よりずっと大きい）ほど式に近づきます（それでも山の手前で充電している時間は放電しないので、式のほうが少し大きく、p19 の C = 100 mF で約 3 %）。T/τ が大きいときのずれはこのためで、表には理想ダイオードの厳密な式（上の θoff と、V0 sin θoff e−(θ−θoff)/(ωτ) = vS となる再充電の角度から計算）も並べました。Vout は vC の平均（シミュレーション）を使っています。
  • L と R の直列では、電流は θ = π を過ぎても流れ続け、角度 β で 0 になります：sin(β − φ) + sin φ · e−β/tan φ = 0（φ = tan−1(ωL/R)、第13回の交流位相調整で α = 0 としたもの）。β から次の周期の始まりまでは電流 0（p21「電流が 0 になる時間が出てくる」）。電流の平均は、コイルの電圧の平均が 0 なので V0(1 − cos β)/(2πR)。
  • L だけ（R = 0）では iL = (V0/ωL)(1 − cos ωt) ≥ 0 なので、ダイオードはずっとオンのままです（p11）。C だけでは、山で V0 まで充電した後、放電する道がないのでずっと V0 です。
  • この回路は、最初の山を過ぎると毎周期同じ波形をくり返します（C は毎周期の山で V0 に戻り、L と R の電流は毎周期 0 から始まる）。そのため 6 周期だけ計算しています。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 720 分割）で、ダイオードがオン・オフする時刻は二分法で求めています。
