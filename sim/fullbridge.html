フルブリッジインバータ（方形波）のシミュレーター

パワーエレクトロニクス 第11回 直流-交流変換（１） p8〜30 / 大阪工業大学
4 つのスイッチを S1・S4 と S2・S3 の組で半周期ずつオンにして、直流の電源 E からプラス・マイナスに振動する電圧（方形波）を作ります（p6〜10）。 負荷は R・L・L＋R から選べます。デッドタイム（全部のスイッチがオフの時間）と還流ダイオードの有無を切り替えると、p21〜30 の「電流の逃げ道」の話が確かめられます。 回路図の線をクリックすると電位（電源の − の線を 0 V とする）、素子をクリックすると電流（矢印の向きが正）が下のグラフに出ます。

このシミュレーターの前提
  • スイッチは理想（オンで 0 Ω、どちら向きにも流せる）。スライドと同じく、オンのスイッチは負荷の電流が逆向きのときも、そのスイッチ自身が流します（区間 I・III の iS1 < 0。p14・p20）。還流ダイオードは、全部のスイッチがオフのデッドタイムの間だけ流れます（p26〜30）。ダイオードも理想（電圧降下 0）です。
  • ゲート信号はスライド p26 と同じです：S1・S4 は 0〜T/2、S2・S3 は T/2 + td 〜 T、T の後にも td のデッドタイム（最初の周期だけは t = 0 から S1・S4 がオン）。td は周期の 20 % までにしています。
  • デッドタイムの間：還流ダイオードがあると、i > 0 なら D2・D3（区間 III′）、i < 0 なら D1・D4（区間 IV′）が流れ、負荷にはそれぞれ −E・+E がかかります。電流が 0 になったらダイオードも止まります。
  • 還流ダイオードがないと、コイルの電流の逃げ道がありません。実際のスイッチもオフで少しだけ電流を流すので、オフのスイッチを 10 kΩ の抵抗としました。コイルの電流はこの抵抗に流れ込み、L/(10 kΩ) 程度の短い時間で 0 になります。そのときスイッチにかかる電圧は「電流 × 10 kΩ / 2」の桁で、実際の回路ならスイッチが壊れます（p22・p24）。
  • 負荷が L だけのときは抵抗がないので、電流の平均は最初の値のまま変わりません。p12 と同じ三角波（±TE/(4L)）にするには、「i(0)」を −TE/(4L) にします。0 から始めると 0〜TE/(2L) の三角波になります。
  • L＋R の定常状態の山は (E/R) tanh(T/(4τ))、τ = L/R（各区間の指数関数をつないだ厳密な値。p16 の逐次近似を続けた先）です。逐次近似の 1 回目の山 TE/(4L) は、τ が T より十分長いときの近似です。
  • p17〜18 のキャパシタ負荷は、理想のスイッチでは電流が無限大のパルスになるので入れていません。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 400 分割）。ゲートの切り替わりは区間の境目に置き、ダイオードの電流が 0 になる時刻は二分法で求めています。
