このシミュレーターの前提
  • 変圧器は結合係数 1 の結合コイル（漏れインダクタンス・巻線の抵抗・鉄心の損失や飽和なし）です。これは「理想変圧器 ＋ 1次側の励磁インダクタンス Lm」と同じで、3 つの巻線の電圧は巻数に比例し（v1 : v2 : v3 = n1 : n2 : n3、○ の側が＋）、電流は n1i1 − n2i2 + n3i3 = n1im を満たします。
  • スライド p34 の値（1次 10 mH・2次 0.1 mH・リセット巻線 10 mH）は、Lm = 10 mH、n2/n1 = √(0.1/10) = 0.1、n3/n1 = 1 にあたります。
  • スイッチとダイオード（D1・D2・リセット用 D3）は理想です。オンの間、2次側には (n2/n1)V0 が出て、D1 → コイル → C・R に流れます。オフの間は D2 が流れて、降圧チョッパーと同じ動きになります。
  • オフの間、励磁電流 im はリセット巻線 n3 と D3 を通って電源に戻ります（1次側の電圧は −(n1/n3)V0）。リセットにかかる時間は (n3/n1)DT なので、D ≤ n1/(n1 + n3)（(n3/n1)DT ≤ (1 − D)T から。n3 = n1 なら D ≤ 0.5）でないと励磁電流が周期ごとに増えていきます（実際の鉄心は飽和します）。
  • 出力のコイルの電流が 0 になると、D1・D2 が止まって電流 0 のまま（電流不連続モード）になります。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 80〜400 分割）で、出力のコイルの電流が 0 になる時刻は二分法、励磁電流が 0 に戻る時刻は式で求めています。
