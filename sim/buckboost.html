パワーエレクトロニクス 第5回 直流-直流変換（１）p37〜47 / 大阪工業大学
回路図の線（節点）をクリックすると、その点の電位（GND を 0 V とする）が下のグラフに出ます。 素子をクリックすると、その素子の電流が出ます（矢印の向きが正）。もう一度クリックすると消えます。 出力の vC（上が＋）はマイナスになるので、授業のスライドと同じく、符号を反転した −vC も出せます（グラフの上のボタン）。回路図の −vC の矢印が下向きなのは、vC（上向き＝上が＋）と逆に、下の線を＋として測った電圧だからです（定常ではプラスになる）。

このシミュレーターの前提
  • スイッチとダイオードは理想（オンで 0 Ω・オフで電流 0、電圧降下なし）。コイル・コンデンサ・抵抗も理想の素子です。
  • vC は授業と同じく、コンデンサの上が＋の向きです。オフの間、コイルの電流は下の線から C・R を下から上に流れるので、vC = −D/(1 − D)·V0 とマイナスになります。D < 0.5 で降圧、D > 0.5 で昇圧です。
  • スライド p45・p46 の出力の段は、符号を反転した −vC（約 +5 V・+12 V）です。ここでも「−vC」の波形をはじめから出しています。
  • オフの間にコイルの電流が 0 になると、ダイオードが止まって電流 0 のまま（電流不連続モード）になります。このときは |vC| が D/(1 − D)·V0 より大きくなります。
  • 計算は 4 次のルンゲ・クッタ法（1 周期を 80〜400 分割）で、コイルの電流が 0 になる時刻は二分法で求めています。
