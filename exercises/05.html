この演習問題は、下記の理解度を確認することを目的としています。

問題1：降圧チョッパー回路の動作と出力電圧

  • スイッチのオンとオフで等価回路を作り、電流の経路とダイオードの役割を説明できるか。
  • KVL からコイルにかかる電圧を求め、定常状態の条件から $v_R = DV_0$ を導けるか。
  • スイッチとダイオードの部分を方形波の電圧源とみなすと、第4回の問題1と同じ回路になることを説明できるか。
  • 2つのスイッチを同時にオン・オフしてはいけない理由を、枝構成式で説明できるか。

問題2：電流の振動の大きさと、計算の近似

  • オンの区間のコイルの電圧と枝構成式から、電流の振動の大きさの式を導けるか。
  • 式から、$L$ やスイッチング周波数を変えると振動の大きさがどう変わるかを説明できるか。
  • 計算で置いた近似（負荷の電圧が一定、コイルの電圧が矩形波）がどのくらい成り立っているかを、負荷の電圧の振動から確かめられるか。

問題3：昇圧チョッパー回路

  • オンとオフの等価回路から、コイル・ダイオード・コンデンサの役割を説明できるか。
  • 定常状態の条件から $v_C = V_0/(1-D)$ を導き、なぜ昇圧になるのかを説明できるか。
  • 電力のつり合いからコイルの電流を求め、電流と電圧の振動の大きさを見積もれるか。

問題4：昇降圧チョッパー回路

  • 定常状態の条件から $v_C = -\dfrac{D}{1-D}V_0$ を導き、出力の符号が反転する理由を説明できるか。
  • 降圧・昇圧・昇降圧の電圧の比をデューティ比で比べられるか。

問題１：降圧チョッパー回路の動作と出力電圧

下図の降圧チョッパー回路について考える。点線の枠の中は制御スイッチ（MOSFET や IGBT）で、周期$T$のうち$0\leq t\lt DT$でオン、$DT\leq t\lt T$でオフになる（$D$はデューティ比）。ダイオードは理想的なもの（オンのときの電圧は$0$）とする。$V_{0}=10\,[\mathrm{V}]$、$D=0.5$、スイッチング周波数$f_\mathrm{sw}=1\,[\mathrm{kHz}]$、$L=30\,[\mathrm{mH}]$、$R=10\,[\Omega]$とする。負荷の電圧$v_{R}$は、1周期のあいだほぼ一定とみなしてよい。以下の問いに答えよ。

  1. スイッチがオンの時とオフの時のそれぞれについて、等価回路を描き、コイルの電流$i_{L}$が流れる経路を示せ。また、オンの時にダイオードに電流が流れない理由を説明せよ。
  2. オンの時とオフの時のそれぞれについて、KVL からコイルにかかる電圧$v_{L}$を$V_{0}$、$v_{R}$を用いて表せ。
  3. 定常状態の条件（1周期の$v_{L}$の積分が$0$）から、$v_{R}$を$D$と$V_{0}$で表し、その値を求めよ。また、コイルの電流$i_{L}$の平均値を求めよ。
  4. ダイオードの両端の電圧（カソード側が高い向き）を$v_{in}(t)$とする。$v_{in}(t)$の波形を$0\leq t\leq 2T$の範囲で描け。さらに、スイッチとダイオードの部分を$v_{in}(t)$という方形波の電圧源に置き換えると、第4回の演習問題1と同じ回路になることを説明せよ。
  5. 制御スイッチとダイオードの代わりに、2つのスイッチを交互にオンオフさせる場合を考える。2つのスイッチが同時にオンになった時と、同時にオフになった時に、それぞれ何が起こるかを、枝構成式を用いて説明せよ。

問題２：電流の振動の大きさと、計算の近似

問題１の降圧チョッパー回路（$V_{0}=10\,[\mathrm{V}]$、$D=0.5$、$R=10\,[\Omega]$）で、コイルの電流の振動の大きさ$\Delta I = I_{\rm max}-I_{\rm min}$を考える。問題１と同じく、負荷の電圧$v_{R}$は1周期のあいだ一定（$v_{R}=DV_{0}$）とみなして計算する。以下の問いに答えよ。

  1. オンの区間（$0\leq t\lt DT$）で、コイルの電流は$I_{\rm min}$から$I_{\rm max}$まで増える。問題１(2)で求めたオンの時の$v_{L}$と、コイルの枝構成式$v_{L}=L\,di_{L}/dt$から、$\Delta I$を$D$、$V_{0}$、$L$、$T$で表せ。また、$f_\mathrm{sw}=1\,[\mathrm{kHz}]$、$L=30\,[\mathrm{mH}]$のときの値を求めよ。
  2. (1)と同じ回路で、(a) $f_\mathrm{sw}=10\,[\mathrm{kHz}]$、$L=30\,[\mathrm{mH}]$、(b) $f_\mathrm{sw}=1\,[\mathrm{kHz}]$、$L=300\,[\mathrm{mH}]$ とした。それぞれ$\Delta I$を求めよ。また、(a)と(b)が同じ値になる理由を、(1)の式から説明せよ。
  3. (1)の条件（$f_\mathrm{sw}=1\,[\mathrm{kHz}]$、$L=30\,[\mathrm{mH}]$）で、コイルの電流の平均値と、$I_{\rm max}$、$I_{\rm min}$を求めよ。また、$\Delta I$は平均値の何％か求めよ。
  4. (1)の式は、$v_{R}$を一定とみなし、コイルの電圧$v_{L}$を矩形波として計算したものである。ところが実際には$v_{R}=Ri_{L}$なので、$i_{L}$が振動すると$v_{R}$も振動する。(3)の$I_{\rm max}$と$I_{\rm min}$から$v_{R}$の最大値と最小値を求め、オンの区間の始めと終わりで$v_{L}$がいくらになるかを求めよ。それを矩形波とみなした値（(1)で使った$v_{L}$）と比べよ。さらに、(2)の(a)の条件ではどうなるかを求め、この近似がよく成り立つためには$L$と$f_\mathrm{sw}$をどうすれば良いか答えよ。

問題３：昇圧チョッパー回路

下図の昇圧チョッパー回路について考える。制御スイッチは$0\leq t\lt DT$でオン、$DT\leq t\lt T$でオフになる。ダイオードは理想的なものとし、コンデンサの電圧$v_{C}$は1周期のあいだほぼ一定とみなしてよい。$V_{0}=5\,[\mathrm{V}]$、$f_\mathrm{sw}=20\,[\mathrm{kHz}]$、$L=700\,[\mu\mathrm{H}]$、$C=500\,[\mu\mathrm{F}]$、$R=28.8\,[\Omega]$とする。以下の問いに答えよ。

  1. スイッチがオンの時とオフの時のそれぞれについて、等価回路を描き、$i_{L}$が流れる経路を示せ。また、オンの時にダイオードに電流が流れない理由と、オンの時に負荷$R$に電流を流しているのは何かを説明せよ。
  2. オンの時とオフの時のそれぞれについて、コイルにかかる電圧$v_{L}$を$V_{0}$、$v_{C}$を用いて表せ。
  3. 定常状態の条件から、$v_{C}=\dfrac{1}{1-D}V_{0}$となることを導け。また、$v_{C}$が$V_{0}$より大きくなる理由を、$D$のとりうる範囲から説明せよ。
  4. $v_{C}=12\,[\mathrm{V}]$にしたい。$D$を求めよ。また、負荷で消費される電力を求め、入力と出力の電力が等しいとしてコイルの電流の平均値を求めよ。さらに、コイルの電流の振動の大きさ$\Delta I = I_{\rm max}-I_{\rm min}$を求め、平均値と比べよ。
  5. オンの区間では、コンデンサだけが負荷に電流を流している。負荷の電流を$v_{C}/R$で一定とみなして、コンデンサの電圧の振動の大きさ$\Delta v_{C}$を求めよ。

問題４：昇降圧チョッパー回路

下図の昇降圧チョッパー回路について考える。制御スイッチは$0\leq t\lt DT$でオン、$DT\leq t\lt T$でオフになる。ダイオードは理想的なものとし、コンデンサの電圧$v_{C}$（向きは図の矢印）は1周期のあいだほぼ一定とみなしてよい。以下の問いに答えよ。

  1. スイッチがオンの時とオフの時のそれぞれについて、等価回路を描き、$i_{L}$が流れる経路を示せ。また、それぞれの区間でコイルにかかる電圧$v_{L}$を$V_{0}$、$v_{C}$を用いて表せ。
  2. 定常状態の条件から、$v_{C}$を$D$と$V_{0}$で表せ。また、$v_{C}$が負になる（入力と出力の符号が反転する）理由を、オフの時にコンデンサに流れ込む電流の向きから説明せよ。
  3. 入力$12\,[\mathrm{V}]$から大きさ$5\,[\mathrm{V}]$の出力を作る$D$と、入力$5\,[\mathrm{V}]$から大きさ$12\,[\mathrm{V}]$の出力を作る$D$をそれぞれ求めよ。また、問題３の昇圧チョッパーで$5\,[\mathrm{V}]$から$12\,[\mathrm{V}]$を作るときの$D$と比べよ。
  4. 降圧・昇圧・昇降圧チョッパーの出力電圧の大きさと$V_{0}$の比を、$0\leq D\lt 1$の範囲で1つのグラフに描け。また、昇降圧チョッパーの比が、降圧チョッパーの比と昇圧チョッパーの比の積になっていることを確かめよ。
